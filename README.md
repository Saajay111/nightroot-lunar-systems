# NightRoot (NRT-01)

**CryoCore Lunar Systems - Conrad Challenge Innovation Stage**

## Project Overview
NightRoot is a proposed self-burrowing lunar pod designed to use lunar regolith as passive thermal protection for extended lunar surface missions.

## Proposed System
- Compact cylindrical pod
- Dual counter-rotating auger concept
- Target burial depth of 30 cm
- Surface station for solar power and communications
- Tether connecting the surface station to the buried pod

## Preliminary Design Parameters

| Parameter | Current Value |
|---|---:|
| Pod length | 280 mm |
