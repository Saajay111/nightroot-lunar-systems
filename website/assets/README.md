# Website assets

Place project-owned media in these folders:

- `images/` — lunar environment and supporting visuals.
- `renders/` — original NightRoot CAD renders, assembly views, and prototype photos.
- `logos/` — approved CryoCore Lunar Systems logo files.

Use images that your team created or has permission to publish. Prefer optimized WebP or PNG files, descriptive filenames, and useful alt text. Do not label concept illustrations as photographs of a tested prototype.

The initial website uses CSS-generated concept artwork as a temporary visual. Replace it with your team's approved CAD renders when they are ready.
